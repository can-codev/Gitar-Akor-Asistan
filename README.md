# Gitar Akor Asistanı

PyQt5 ile geliştirilmiş, modern arayüze sahip bir **Gitar Akor Asistanı** uygulaması.

Bu uygulama ile:

- Akorları listeleyebilir
- Akor şemalarını görebilir
- Parmak numaralarını inceleyebilir
- Akor pratiği yapabilir
- Mikrofon ile temel nota/akor tahmini alabilir
- Sanal piyano kullanabilirsiniz

---

## Özellikler

### 1. Akor Sözlüğü
- Majör, minör, 7'li ve maj7 akorları listeler
- Arama kutusu ile akor bulunabilir
- Akor şeması görsel olarak gösterilir
- Parmak numaraları diyagram üzerinde gösterilir

### 2. Akor Pratiği
- Rastgele akor gösterir
- Doğru / yanlış takibi yapılır
- Skor, başarı oranı ve seri bilgisi tutulur
- Süreli pratik yapılabilir

### 3. Akor Tanıma (Test Edilmedi)
- Mikrofon girişinden ses seviyesi alınır
- Temel frekans analizine göre nota/akor tahmini yapılır
- Tanınan akor geçmişi listelenir

### 4. Sanal Piyano
- Klavye ile nota çalınabilir
- Oktav değiştirilebilir
- Sustain açılıp kapatılabilir
- Ses seviyesi ayarlanabilir
